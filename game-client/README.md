# Ancien client TSI — référence historique

<badge>ARCHIVÉ — NE PAS ÉTENDRE</badge>

Ce dossier contient une ancienne implémentation PlayCanvas conservée pour consultation et récupération ciblée de code.

Le runtime officiel est désormais `prototype/`. Toute nouvelle fonctionnalité, correction de gameplay, intégration d'assets ou optimisation Android doit être réalisée dans `prototype/`.

Ne pas réactiver une CI ou un déploiement indépendant pour ce dossier. Avant de porter un élément utile, vérifier sa compatibilité avec le client actif et ajouter des tests sur le runtime officiel.

Décision : [ADR-003 — Architecture runtime unique](../docs/adr/ADR-003-single-active-runtime.md).
